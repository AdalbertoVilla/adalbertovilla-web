# Sitio web personal | Adalberto Villa

Mi sitio web personal reúne mi visión, trayectoria y publicaciones sobre innovación, estrategia y tecnología.

**Visita el sitio:** [www.adalbertovilla.com](https://www.adalbertovilla.com)


## Objetivo del proyecto

Crear un espacio digital para compartir mis ideas, mi experiencia profesional y mis publicaciones, mientras desarrollo conocimientos prácticos sobre la creación y administración de sitios web.

Este sitio también es el primer proyecto de mi portafolio personal.


## Contenido del sitio

- Mi visión sobre la innovación.

- Mi propuesta basada en cultura, planeación e indicadores.

- Mi trayectoria y formación.

- Mi libro y publicaciones.

- Enlaces a mis columnas y artículos en LinkedIn.



## Tecnologías y herramientas

- **HTML:** estructura y contenido del sitio.

- **CSS:** diseño, colores y adaptación a diferentes pantallas.

- **JavaScript:** funciones de navegación.

- **Git y GitHub:** historial y respaldo de los archivos.

- **GitHub Desktop:** gestión de cambios desde la computadora.

- **Vercel:** publicación del sitio.

- **GoDaddy:** administración del dominio.



## Proceso y aprendizaje

El sitio comenzó como un proyecto en ChatGPT Sites. Posteriormente, con apoyo de inteligencia artificial, recuperé y organicé sus archivos para administrarlos en GitHub y publicarlos mediante Vercel con mi dominio personal.

Durante el proceso practiqué la organización de archivos, el uso de GitHub Desktop, la publicación de un sitio y la configuración de un dominio.
